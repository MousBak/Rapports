# Rapports de projets Data

> Documentation / Portfolio Data

## Vue d'ensemble

Dépôt centralisant des rapports PDF et documents liés à plusieurs projets data : audit Excel, dashboard Power BI, Big Data Chicago, moteur de recommandation, segmentation client et prévision boursière.

## Objectifs du projet

- Regrouper les livrables de synthèse des projets.
- Faciliter la consultation des rapports par un recruteur.
- Montrer la capacité à documenter une analyse et ses résultats.
- Servir de complément au portfolio GitHub Pages.

## Démarche

- Organisation de documents PDF/DOCX par projet.
- Rapports orientés contexte, méthodologie, résultats et recommandations.
- Mise à disposition de livrables lisibles sans exécuter le code.

## Stack technique

- PDF
- DOCX
- Documentation projet
- Data Storytelling
- Portfolio
